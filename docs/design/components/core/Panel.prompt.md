The section container — `surface`, `radius-md`, `h2` header at `text-section` with the hairline tick at its leading edge.

```jsx
<Panel title="פרטי ההזמנה" subtitle="עודכן לפני 4 דקות" actions={<Button variant="ghost" size="sm">עריכה</Button>}>…</Panel>
```

Use `Panel` for a section of a page and `Card` for a repeated object inside one. The tick is the system's only ornament — one per panel header, never sprinkled elsewhere.
