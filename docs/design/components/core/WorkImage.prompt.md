Squared reference photo — "what am I making", not identity. Returns `null` when there is no image.

```jsx
<WorkImage src={order.referencePhotoUrl} alt="תמונת התייחסות" size={56} />
```

Never on a production-board card: photos appear in the peek, the work-order hub and My Work cards. Its square shape is what keeps it from being confused with a circular worker avatar.
